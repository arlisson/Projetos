DOCUMENTAÇÃO ETL - MAPEAMENTO JSON -> MODELS

==================================================
1) PROJECT ESTABLISHMENT DATA -> TMProjeto
==================================================
JSON Field                        -> Model Field
--------------------------------------------------
id                                -> TMProjeto.id
uuid                              -> TMProjeto.uuid
organization-name                 -> TMProjeto.organizacao
project_name                      -> TMProjeto.nome
status                            -> TMProjeto.status
planting_start_date               -> TMProjeto.data_inicio_plantio
planting_end_date                 -> TMProjeto.data_fim_plantio
continent                         -> TMProjeto.continente
country                           -> TMProjeto.pais
trees_grown_goal                  -> (dados_extras)
total_hectares_restored_goal      -> TMProjeto.hectares_objetivo
survival_rate                     -> TMProjeto.taxa_sobrevivencia
year_five_crown_cover             -> TMProjeto.meta_cobertura_cinco_anos
description_of_project_timeline   -> TMProjeto.descricao_timeline
history                           -> TMProjeto.historico
other_additional_documents, file  -> TMProjeto.arquivos_adicionais

ASSOCIAÇÕES DE PROJETO:
- TMProjetoTemEspecieArvore  <- treeSpecies
- TMProjetoTemTecnica        <- restoration_strategy
- TMProjetoTemTipoUsoSolo    <- land_use_types
- TMMembroProjeto            <- (não no JSON, vem de planilha de pessoas)

--------------------------------------------------

ASSOCIAÇÕES DE RELATÓRIO DE SÍTIO:
- TMRelatorioSitioFoto            <- photos
- TMRelatorioSitioTemEspecieArvore <- treeSpecies
- TMRelatorioSitioHasDemografia   <- workdays_* (dias pagos/voluntários no nível do sítio)
- TMDisturbio                     <- problemas/impactos descritos


==================================================
5) DEMOGRAFIA -> TMDemografia*
==================================================
Origem JSON: campos workdays_* (ex.: workdays_paid, workdays_volunteer, workdaysPaidProjectManagement)

- TMDemografiaDiasUteis
  tipo       -> pago / voluntario
  categoria  -> área (gestão, viveiro, campo etc.)

- TMDemografiaHasGenero
  origem: gender:(x:male)(y:female)

- TMDemografiaHasFaixaEtaria
  origem: age:(n:youth)(m:adult)

- TMDemografiaHasEtnia
  origem: ethnicity:(z:unknown)

Esses dados se associam tanto a TMRelatorioProjeto quanto a TMRelatorioSitio via tabelas intermediárias:
- TMRelatorioProjetoHasDemografia
- TMRelatorioSitioHasDemografia

==================================================
RESUMO FINAL
==================================================
- Projeto (TMProjeto)  <- Project Establishment JSON
- Sítio (TMSitio)      <- Site Establishment JSON
- Relatório Projeto (TMRelatorioProjeto) <- Project Reports JSON
- Relatório Sítio (TMRelatorioSitio)     <- Project Reports JSON (detalhes por site)
- Demografia (TMDemografia*) <- workdays_* fields
- Associações extras: espécies, técnicas, uso do solo, fotos, distúrbios
